# SketchPad 需求扩展：练习册 + 草稿纸

> 文档性质：产品需求（PRD 草案），不是实现方案，未修改代码。  
> 基线版本：v2.3（提交 `7567ebf`，375 tests passed）  
> 前置文档：[体验与界面评审](2026-10-21-ux-review.md)（快捷键、布局、视觉问题）  
> 本文聚焦：**学生做练习时，在 PDF 上做笔记 + 随手打草稿**这条主线。

---

## 0. 一句话定位

> **一本可以批注的练习册，配一本随时能翻开的草稿纸。**

不是“能看 PDF 的阅读器”，也不是“画板”。它要解决的是学生做题时的连续动作：

```
翻到作业 → 看题 → 圈关键词 → 算草稿 → 写下答案 → 标记不会 → 对答案 → 复习错题
```

现有版本已经能“在 PDF 上画线”，但还不足以支撑这条链路。下面按“学生真正会怎么用”拆需求，而不是按“软件有哪些功能”罗列。

---

## 1. 我理解的核心诉求

### 1.1 三个不可替代的点

| 点 | 说明 | 现状 |
|---|---|---|
| **练习册感** | PDF 是题面，批注直接叠在题上；翻页、题号、答案位置都要像纸质练习册一样自然 | 只有逐页笔迹，没有题目、答案、状态的概念 |
| **草稿纸感** | 算题时随手就能写，不用切窗口、不用找文件；草稿和当前题能对上 | 有独立草稿窗，但与 PDF、题目完全脱节，且不保存 |
| **复习闭环** | 做错的题要能快速找回来，重新做，看到自己当时的草稿和批注 | 只有笔迹，没有“题卡/错题/掌握状态” |

### 1.2 与通用 PDF 阅读器的区别

| 通用阅读器 | 本产品 |
|---|---|
| 以“读”为主 | 以“做”为主 |
| 批注是附属功能 | 批注是主要工作流 |
| 草稿是另一个应用 | 草稿是练习界面的一部分 |
| 文件式组织 | 题目式组织 |
| 保存整份文档 | 保存“题目 + 笔记 + 草稿 + 状态” |

### 1.3 产品原则

1. **不打断做题**：任何常用动作不超过 1 次点击 / 1 个快捷键。
2. **草稿优先**：草稿入口必须比“打开计算器”还快。
3. **题面不动**：批注、遮罩、题卡都不改原 PDF，只写 sidecar。
4. **默认安全**：自动保存默认开，关闭/切换/退出三个出口都不静默丢东西。
5. **像纸但不模拟纸**：保留纸的直觉（翻页、草稿、标记），不模拟纸张的缺点（不能撤销、不能搜索、不能复制）。

## 2. 用户与场景

### 2.1 目标用户

| 用户 | 设备 | 主要科目 | 关键诉求 |
|---|---|---|---|
| 初中/高中生 | Windows 笔记本 + 鼠标/触控板，少数手写笔 | 数学、物理、化学 | 做题快、草稿方便、错题能回看 |
| 大学生 | 轻薄本/二合一平板 | 高数、线代、英语阅读 | 大量演算、长文档、夜间复习 |
| 自学者 | 台式机 | 习题集、考证资料 | 不想打印，想反复做 |

### 2.2 典型练习册形态

- **一页多题**：数学练习册、英语阅读、物理选择题。
- **一题多页**：大题、实验题、阅读理解。
- **答案在书后**：需要快速跳到答案页。
- **扫描版**：没有文本层，搜索不可用，页面可能轻微倾斜。
- **电子版**：有文本层，可以搜索、可以复制题目。

> 需求必须同时兼容“扫描版”和“电子版”，不能假设 OCR 一定存在。

### 2.3 核心用户故事

| ID | 用户故事 |
|---|---|
| US-1 | 我打开作业后，想直接回到上次停下的题，而不是从头翻。 |
| US-2 | 我想把第 3 题框起来，标成“不会”，复习时只看这些题。 |
| US-3 | 我算这道题时，想立刻在旁边打草稿，不想另开窗口或找草稿纸。 |
| US-4 | 对答案时，我想先遮住答案和解析，做完再刮开。 |
| US-5 | 我想用荧光笔划重点、用文字写“公式记错”，而不是只能画线。 |
| US-6 | 我想把错题连同我的草稿导出成一张图，发给同学或放进错题本。 |
| US-7 | 复习时我想隐藏原来的答案和笔记，重新做一遍。 |
| US-8 | 我关程序、换文件、崩溃时，都不想丢任何批注和草稿。 |

## 3. 核心概念模型

先把概念定清楚，后面的需求才不会散。

| 概念 | 定义 | 与现有实现的差距 |
|---|---|---|
| **练习册（Document）** | 一份 PDF + 它的全部批注、题卡、草稿、书签 | 已有 PDF + sidecar，但 sidecar 只有笔迹 |
| **题卡（Card）** | 页面上一个矩形区域，代表“一道题”；有编号、状态、备注 | 无 |
| **状态（Status）** | 未做 / 在做 / 不会 / 待订正 / 已掌握 | 无 |
| **批注（Annotation）** | 笔迹、荧光笔、文字、形状、印章、遮罩 | 只有笔迹 |
| **草稿页（Scratch Page）** | 一张草稿纸，可独立，也可绑定到某道题 | 有独立草稿窗，但不分页、不绑定、不保存 |
| **答案遮罩（Mask）** | 盖住答案/解析的矩形，可点击或刮开 | 无 |
| **书签（Bookmark）** | 页面级标记，用于快速回到重点页 | 无 |
| **颜色语义（Color Tag）** | 给颜色起名，如“重点/疑问/订正” | 只有颜色本身 |

### 3.1 一段完整的做题记录长什么样

```
第 12 页
├─ 题卡 #3  状态：不会  备注：辅助线没想到
│  ├─ 题面批注：圈出“中点”，画了一条虚线
│  ├─ 关联草稿页：SP-03（含 2 次尝试、1 个划掉的错误）
│  └─ 答案遮罩：盖住解析区，已刮开
├─ 题卡 #4  状态：已掌握
└─ 荧光笔：标出题干条件
```

这份记录既能“回到题面”，也能“回看草稿”，还能“筛出不会的题”。

## 5. 详细需求

### R1 打开与定位

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| R1-01 | 拖放 PDF 到窗口即打开 | P0 | 拖入 `.pdf` 直接进入文档模式；非 PDF 有明确提示 |
| R1-02 | 双击文件 / 命令行参数打开 | P1 | `SketchPad.exe lecture.pdf` 直接打开该文件 |
| R1-03 | **打开后定位页首**（修当前 bug） | P0 | 打开任意竖版 PDF，首屏能看到页首标题；横版页顶部对齐 |
| R1-04 | 记住每份文档的上次页码与缩放 | P0 | 重新打开回到上次位置；可在设置关闭 |
| R1-05 | 最近文件 + 文件缺失标记 | P1 | 不存在的文件置灰，tooltip 显示完整路径 |
| R1-06 | 大文件异步打开 + 进度 + 取消 | P0 | 100MB/500 页 PDF 打开时 UI 不冻结；可取消 |
| R1-07 | 扫描版提示 | P1 | 无文本层时提示“该 PDF 无文字层，查找不可用”，不报错 |

**说明**：R1-04 和题卡/书签共用同一份“阅读位置”数据。不要分别存两套。

### R2 题卡系统（核心）

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| R2-01 | 框选题目区域生成题卡 | P0 | 选“题卡工具”后拖矩形，松手弹出题号/状态输入；可取消 |
| R2-02 | 题号：手动输入 + 页内自动序号 | P0 | 默认按页内顺序生成 `1、2、3`；允许改成 `12(2)` 这种自定义编号 |
| R2-03 | 五种状态：未做 / 在做 / 不会 / 待订正 / 已掌握 | P0 | 颜色区分；点击题卡即可切换；状态变化立即写入 sidecar |
| R2-04 | 题卡侧栏列表 | P0 | 按页分组；显示题号、状态、备注摘要；点击跳转并高亮 |
| R2-05 | 题卡详情 | P0 | 可写备注；显示关联草稿页缩略图；显示该题的批注数量 |
| R2-06 | 一键“不会”标记 | P0 | 右键题面或题卡列表，一键标记；题卡角标变红 |
| R2-07 | 题卡区域可拖动/缩放/删除 | P1 | 拖动不误触批注；删除有确认或可撤销 |
| R2-08 | 题卡坐标与缩放/旋转一致 | P0 | 缩放后题卡边框仍贴合题目；旋转页不错位 |
| R2-09 | 题卡右键菜单 | P1 | 切换状态、开草稿、复制题号、删除、导出该题 |
| R2-10 | 自动识别题号 | P2 | 电子版 PDF 可从文本层提取题号候选；扫描版不做承诺 |

**关键规则**

- 题卡是**逻辑对象**，不是画在 PDF 上的矩形；导出时默认不打印边框，可选打印。
- 一个区域只能属于一个题卡；重叠时后建的覆盖先建的，并提示。
- 题卡可以没有编号（“未命名题”），但复习列表里按页序排列。

**文字笔记的细节**

- 输入框宽度默认 240pt，可拖拽改宽；高度随文字增长。
- 字体跟随系统，字号 10/14/18 三档；颜色继承当前色。
- 双击进入编辑；空白内容自动删除。
- 导出为 PDF 时，文字作为文本写入（可搜索），不是描边。

**草稿保存的产品决策（必须确认）**

现状是“草稿关程序即丢”，这符合“草稿纸”的隐喻，但不符合“复习时想看我当时的演算”的需求。

建议：

- **默认随文档保存**（sidecar 内 `scratch`），关闭文档/退出时随批注一起保存；
- 设置里提供“草稿不保存（退出即清空）”开关，给坚持纸感的人；
- 草稿默认不导出到 PDF，只在需要时手动导出/贴回；
- 草稿页也支持“清空本页”，但走撤销栈。

## 6. 关键流程

### 6.1 第一次使用

```
启动 → 空状态：拖入 PDF / 打开文件 / 直接写
     → 打开作业.pdf
     → 定位页首，标题显示“作业.pdf · 1/26”
     → 右下角提示“按 F2 打开草稿纸，按 B 开始批注”
     → 3 秒后淡出，不再打扰
```

### 6.2 做一道题（目标 ≤ 4 个动作）

```
1. 滚动到第 3 题
2. 选题卡工具，框住第 3 题 → 输入题号 3，状态“在做”
3. 按 F2 打开右侧草稿 → 自动新建草稿页并绑定题卡 → 演算
4. 回到题面写答案；不会就右键题卡 → “标记不会”
```

可选动作：荧光笔划条件、文字写“公式记错”、遮罩盖住答案。

### 6.3 对答案

```
点击“显示全部答案” → 临时显示所有遮罩
→ 逐题批改：√ / × / ?
→ 错题改状态“待订正”或“不会”
→ 再次点击恢复遮罩
```

### 6.4 复习

```
打开作业 → 侧栏“题卡” → 筛选“不会/待订正”
→ 进入复习模式：只显示这些题，隐藏原笔记
→ 重新做 → 更新状态“已掌握”
→ 可选：导出错题卡片
```

### 6.5 关闭与恢复

```
关闭文档 → 有未保存 → “保存 / 丢弃 / 取消”
→ 保存成功 → 状态栏“已保存 14:32”
→ 异常退出 → 下次打开提示恢复临时文件
```

## 7. 界面结构建议

### 7.1 练习模式（默认）

```
┌ 标题栏  lecture03.pdf — SketchPad · 3/26 · ●        ⚙ ─ □ ✕ ┐
├ 菜单   文件  编辑  视图  工具  复习  帮助                      │
├ 工具栏 ↶ ↷ │ ✏ H E T ▭ │ 粗细 │ 当前色 │ 题卡 │ 🗑 │ 草稿      │
├───────────────┬──────────────────────────────┬───────────────┤
│ 侧栏（可折叠） │                              │ 草稿（可折叠） │
│ 目录/页面/题卡 │          PDF 题面            │ 草稿页 1/3    │
│ /笔记          │                              │ 网格纸        │
│               │                              │               │
├───────────────┴──────────────────────────────┴───────────────┤
│ 题卡条：3●不会  4○未做  5✓已掌握  ...        缩略图可横向滚动  │
├──────────────────────────────────────────────────────────────┤
│ 状态栏  3/26 · 缩放 82% · 已保存 14:32 · 当前题 #3            │
└──────────────────────────────────────────────────────────────┘
```

设计要点：

- **右侧草稿是核心**，不是附属浮窗；默认宽度 35%，可拖。
- **底部题卡条**是练习册的“目录”，比纯缩略图更符合做题心智。
- 侧栏默认收起，避免挤压题面；需要目录/题卡列表时再展开。
- 工具栏只保留高频工具；形状、印章、贴纸收进“更多”。
- 当前题卡、当前草稿页、当前工具三者始终在状态栏可见。

### 7.2 草稿三形态

| 形态 | 触发 | 适用 |
|---|---|---|
| 右侧分栏 | `F2` | 常规做题，一边看题一边算 |
| 浮窗（可钉住） | `F2` 再按 / 拖出 | 题面需要全宽时；浮在角落 |
| 全屏草稿 | `F3` 或双击草稿标题 | 大题演算、画图 |

> `F3` 目前建议留给“查找下一个”，因此全屏草稿建议用 `Shift+F2` 或双击标题，避免冲突。

### 7.3 空状态与引导

- 首次启动：三行提示“打开 PDF / 直接写 / 按 F2 草稿”，可“不再显示”。
- 第一次打开 PDF：提示一次“框选题目可以建题卡”，不重复。
- 第一次开草稿：提示一次“草稿会随作业保存”，给“知道了”。

## 11. 不做什么

| 项 | 原因 |
|---|---|
| 云同步/账号 | 与本地离线定位冲突 |
| 协作批注 | 需要后端与权限 |
| 自动判题/给分 | 不同科目规则差异大，容易做错 |
| 完整公式编辑器 | 先用文字 + 手写；公式编辑是另一个产品 |
| AI 解题/问答 | 隐私、准确性、成本都不适合当前阶段 |
| PDF 排版编辑 | 练习册工具不需要改原文档 |
| 通用插件系统 | 维护成本高于收益 |
| 草稿无限画布（v3.0 前） | 交互和存储都复杂，先把分页草稿做扎实 |
