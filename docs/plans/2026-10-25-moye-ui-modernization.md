# 墨页 UI 现代化方案：樱雾浅粉 + 轻二次元

日期：2026-10-25
状态：Stage 1 已实现（浅桃主壳），待确认真实观感
范围：只改视觉层（颜色、字体、间距、圆角、边框、状态、图标描边、分组）；不改功能、文案、控件顺序、快捷键、数据格式与交互流程。

## 1. 方向选择

用户指定：二次元动漫少女风格，浅粉色主题。这里把它收敛成“轻二次元”，避免把阅读/批注工具做成痛贴主题。

| 档位 | 做法 | 风险 | 建议 |
|---|---|---|---|
| A 轻二次元 | 浅桃/奶油白外壳、深可可文字、柔和圆角、樱瓣细节；角色只出现在空态/关于 | 最稳，仍然像工具 | **本轮采用** |
| B 角色陪伴 | 空态、设置头图、笔记侧栏加入 Q 版角色小图；不做待机动画 | 角色会占空间，可能分心 | 可作为 A 的补充 |
| C 主题化 | 樱花纹理、角色壁纸、全套可爱图标、粉色画布 | 降低可读性，改动面大 | 不做 |

结论：**A 为主，B 只保留一个很小的角色锚点**。工作区（PDF/笔记画布）不铺角色、不铺纹理，保证长时间阅读和批注。

## 2. 现状审视

保留：

- 36px 标题栏 + 40px 单行工具栏，垂直空间省。
- 深灰外壳、纯图标按钮、无边框窗口的整体骨架。
- PDF 页面优先，工具栏退居其次。

要改：

| 问题 | 处理 |
|---|---|
| 深灰外壳与粉色主题冲突 | 外壳整体改为浅粉/奶油白，建立浅色层级 |
| 工具栏控件挤、分隔弱 | 保持顺序和数量，只加强分组、间距和选中态 |
| 选中态是高饱和蓝方块 | 改为浅桃底 + 深可可图标/陶土描边，降低抢眼程度 |
| 白字/白图标在浅底不可见 | `theme.TEXT` 改为深墨色，图标同步改深色；单独审计硬编码白 |
| 标签像 IDE | 改为浅色书签/纸张标签，当前标签白色浮起 |
| 状态栏是一整句灰字 | 改为“临时消息 + 数据 chip”，信息不减少 |
| 设置面板边框多、留白少 | 改为白色卡片 + 分组标题 + 细分隔 |
| 主窗蓝、批注绿、色板红各说各话 | UI 强调色统一为陶土桃；绿色只留批注；色板颜色值不变 |
| 粉白对比不足 | 所有文字用深可可/陶土，粉只做底和强调 |

硬约束：

- 不减控件、不换位置、不改快捷键、不改按钮可见性。
- 不改 PDF 页面颜色、导出、sidecar、笔记数据。
- 本轮不改草稿画布底色：草稿是深色绘图面，浅粉只包外壳；否则现有浅色墨迹会在浅底上消失。浅色纸面留到后续单独方案（需要自动深色墨逻辑）。
- 不引入新字体文件、新图标包或图片依赖；角色直接复用现有 `app.png`。

## 3. 设计 brief

- 用户与任务：长时间看讲义、写字、划重点、开笔记；需要快速切工具，视觉不能抢注意力。
- 目标感受：柔和、干净、有一点点二次元手帐感，但首先是一个可靠的工具。
- 视觉隐喻：**晨雾樱花 + 手帐纸页**。外壳像淡桃色的桌面，标签像书签，当前工具像一枚陶土色印章，角色只是桌角的小摆件。
- 构图：标题栏 / 菜单栏 / 工具栏三条浅色横带，内容区保持 PDF 白页；状态栏是一条浅粉信息带。
- 关键交互：悬停只提亮；选中用浅桃底 + 陶土描边/深可可图标；破坏性动作不用粉色。
- 透明感：主窗自绘桃色渐变 + 光斑/花瓣，标题栏、菜单栏、工具栏、状态栏使用半透明玻璃底；不做系统级 Acrylic，避免手写/滚动掉帧。
- 第一版最小范围：主题 token、标题栏/标签、工具栏、状态栏、空态、菜单。设置/浮层放第二阶段。

## 4. Tokens

### 4.1 颜色

| Token | 建议值 | 用途 |
|---|---|---|
| `SHELL` | `#FFE9F1` | 窗口底、标题栏底（暖白桃） |
| `TOOLBAR_BG` | `#FFF4F8` | 菜单栏、工具栏底 |
| `SURFACE` | `#FFFCFD` | 按钮、输入框、浮层 |
| `SURFACE_HOVER` | `#FFDCE8` | 悬停 |
| `SURFACE_PRESSED` | `#FFCEDF` | 按下 |
| `BORDER` | `#F6C7D8` | 常规分隔 |
| `BORDER_STRONG` | `#ECABC3` | 输入框/浮层边界 |
| `TEXT` | `#4B2F38` | 主文字、图标（深可可） |
| `TEXT_DIM` | `#7D5862` | 次级文字 |
| `TEXT_MUTED` | `#9A7681` | 辅助文字（仅大字号/非关键） |
| `ACCENT` | `#A84E35` | 主强调：焦点、选中描边、菜单高亮（陶土桃） |
| `ACCENT_SOFT` | `#FFD6E3` | 选中底、浅染 |
| `ACCENT_HOVER` | `#8F3F2A` | 强调悬停 |
| `ACCENT_BORDER` | `#E59CB2` | 浅桃描边、焦点环 |
| `DANGER` | `#A33A2A` | 删除/错误 |
| `DANGER_SOFT` | `#FFDDE3` | 关闭键悬停 |
| `WARNING` | `#8A5A00` | 未保存提醒 |
| `SUCCESS` | `#2F7D5B` | 已保存 |
| `PAPER` | `#FFF5F8` | 空态纸面提示，不用于 PDF |

对比度基线：

- `TEXT` 在 `SHELL` 上约 10.1:1。
- `TEXT_DIM` 在 `SHELL` 上约 5.3:1。
- `ACCENT` 在 `SHELL` 上约 5.3:1。
- 白字在 `ACCENT` 填充上约 5.3:1。
- 不用 `#F2A88F` 级别的浅桃做小字（对比不足）；它只做底色。

### 4.2 形状与间距

- 圆角：小控件 6px、工具栏分组 10px、标签 8px、卡片 12px、对话框 14px。
- 间距：4 / 8 / 12 / 16 / 24；工具栏内 4px，组间 8px。
- 描边：常态 1px `BORDER`，浮层 1px `BORDER_STRONG`，焦点 2px `ACCENT`。
- 阴影：浮层/当前标签用极轻阴影；工具栏不投影，避免 40px 高度变脏。

### 4.3 字体

- 字体族：`Microsoft YaHei UI`，回退 `Segoe UI`, `sans-serif`。
- 字号：11 辅助、12 正文/状态、13 按钮/标签、15 空态标题、18 关于标题。
- 字重：常规 400，控件/标签 500，品牌/标题 600；不超过两个层级同时加粗。
- 数字：粗细、页码、缩放、笔迹数统一 tabular numerals。

### 4.4 图标与角色

- 现有图标保留，统一 1.6–1.8px 描边；`theme.TEXT` 改深墨后图标自动变深。
- 选中工具：`ACCENT_SOFT` 底 + `ACCENT` 1px 描边/深墨图标，不用整块高饱和填充。
- 白色墨色块（`#e8eaed`）在白色 surface 上补 1px `BORDER_STRONG`，否则看不见。
- 角色：只在空态/关于/设置头图使用 `sketchpad/assets/app.png`，建议 64–96px 圆形或圆角小卡；不加待机动画、不铺在画布上。
- 樱瓣细节：最多在空态/设置头图出现 2–3 个低透明度 QPainter 花瓣；不进入工具栏和阅读区。

## 5. 各表面

### 标题栏 / 标签

- 底色 `SHELL`，品牌「墨页」13px/600 深墨；去掉灰色小字感。
- 标签 26px 高、8px 圆角；当前标签 `SURFACE` + `BORDER` + 轻阴影，非当前透明、hover `SURFACE_HOVER`。
- 未保存圆点用 `WARNING`；关闭键只在 hover/当前标签显示。
- 窗口按钮 hover 浅粉，关闭仍用 `DANGER`。

### 菜单栏 / 菜单

- 菜单栏底 `PANEL`，12px；菜单项 6px 圆角，选中用 `ACCENT_SOFT` + 深可可字。
- QMenu 白底、1px `BORDER_STRONG`、8px 圆角、6px 内边距；快捷键右对齐、用 `TEXT_MUTED`。
- 禁用项用 40% 透明度，不要用纯灰。

### 工具栏

- 白/奶油底，五段分组：历史 / 工具 / 粗细 / 颜色 / 动作；分隔线 `BORDER`，组间 8px。
- 选中工具：`ACCENT_SOFT` 底 + `ACCENT` 边框 + 深墨图标；hover `SURFACE_HOVER`。
- 四档粗细圆点、滑杆、数字合并为一个“粗细 chip”：滑杆轨道 `#F4C7D9`，已选段 `ACCENT`，手柄白色 + `ACCENT` 环。
- 色板 18px，白/浅色块加 1px `BORDER_STRONG`；当前色 24px 环；取色器按钮保持原逻辑。
- 清屏/删除类图标与普通工具拉开：hover 用 `DANGER` 淡底，不改变位置。
- 保持 40px 高度与 28px 点击区；900px 窄窗先量 `sizeHint()` 再定间距。

### 状态栏

- 浅粉底、顶部 1px `BORDER`；左侧临时消息，右侧四枚 chip：色点+HEX、粗细、页码/缩放、保存状态。
- chip 之间 1px 分隔，数字 tabular；保存成功用 `SUCCESS`，未保存用 `WARNING`。
- 不删任何信息，只把长句拆成可扫读单元。

### 空态

- 保留原文案与“打开文件/新建笔记”两个入口；加 `app.png` 64px 圆角头像作为唯一角色锚点。
- 标题 15px/600，提示 12px `TEXT_DIM`，快捷键用小 kbd 胶囊；背景 `SHELL`，不加整屏角色壁纸。

### 设置

- 5 个 tab 保留，改成 pill；选中白底 + `ACCENT_SOFT` 边，不再用底部蓝线。
- 页面为白卡片，分组用“标题 + 1px 分隔 + 16px 留白”，去掉 QGroupBox 外框。
- 输入框/下拉/滑杆统一 6px 圆角与 `BORDER_STRONG`；主按钮浅桃底深可可字/陶土描边，次按钮白底描边。
- 快捷键捕获态使用 `ACCENT` 2px 焦点环。

### 查找 / 最近 / 关闭确认 / 关于

- 查找条：白色浮层、10px 圆角、1px 粉边、轻阴影；输入 focus 粉描边；计数 tabular。
- 最近列表：白底、hover 浅粉；路径用 `TEXT_MUTED`，文件名用 `TEXT`。
- 关闭确认：延续现有主窗内遮罩，遮罩改深可可透明（`rgba(79,58,51,0.35)`），面板白/粉。
- 关于：头像 + 名称 + 版本；不加外链和多余文案。

### 笔记卡片 / 独立窗口

- 卡片表面 `SURFACE`，外框 1px `BORDER_STRONG`，圆角 12–14px；去掉亮灰外框。
- 标题行白/浅粉，工具行 `SURFACE_HOVER`；纸色、横线、笔迹颜色完全不变。
- 卡片阴影极轻；不把角色放进笔记卡，避免遮挡内容。

### 全屏批注

- 浮动条：`PANEL` 白粉底 + 1px `BORDER_STRONG` + 10px 圆角 + 轻阴影；横/竖排尺寸不变。
- 选中态：`ACCENT_SOFT` 底 + 深可可图标/陶土描边；穿透/钢笔/橡皮仍互斥。
- 四档圆点 + 滑杆 + 数字保留；滑杆粉色；色板与主窗一致。
- 因为要浮在任意内容上，保留 1px 深色外描边或足够阴影，避免落在白页上“消失”。

### 截图工具条

- 截图区域本身保持原样；工具条改为白粉底、10px 圆角、28px 按钮、浅桃选中态/陶土描边，保证截图可读性。
- 不做深色玻璃，不加纹理。

## 7. 验收

- 现有 UI/布局/快捷键测试全部通过；控件数量、顺序、可见性不变。
- 900px 窄窗工具栏不溢出；150% 缩放下 1px 边框和滑杆不发虚。
- 文字对比度：正文/次级文字达到 AA；粉底不承载小字；选中态同时有底色+描边/图标变化。
- 真实截图：空态、PDF、草稿、设置、笔记窗口、全屏批注、截图工具条；由程序抓取，不操控鼠标。
- 主任务路径不变：打开 PDF、写字、荧光笔、橡皮、笔记、查找、设置、导出。
- 不改 PDF 内容、sidecar、导出、字色/纸色数据。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 浅色主题下现有白图标不可见 | `theme.TEXT` 统一改深墨；逐个审计硬编码白色/浅色图标 |
| 粉底低对比 | 粉只做底，文字用深可可/陶土；小字不用浅桃 |
| QSS 误伤原生颜色对话框 | 只按 objectName 限定；保持原生 QColorDialog |
| 工具栏在 900px 溢出 | 先量 `sizeHint()`，组间距 4/8px；不增减控件 |
| 标签拖拽热区被样式破坏 | 只改 QSS，不改 WorkspaceTabs 鼠标逻辑 |
| 全屏批注浮在白页上看不清 | 保留 1px 深色外描边/足够阴影，横竖排实测 |
| 浅色画布让旧墨迹消失 | 本轮不改画布底色；留到 Stage 4 单独处理 |
| 二次元过度 | 角色只放空态/关于；工作区不铺角色、纹理和动画 |
| 测试写死了旧颜色 | 更新 `tests/test_theme_offscreen.py` 等颜色断言，布局/行为断言不动 |
