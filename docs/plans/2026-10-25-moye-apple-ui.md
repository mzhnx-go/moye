# 墨页 Apple 式整体 UI 方案

日期：2026-10-25
状态：方向 A 已展开为实施计划：`docs/plans/2026-10-26-moye-apple-topchrome.md`（2026-10-26）
范围：只改外观层与容器排布；不改功能、控件顺序、快捷键、数据、导出与交互逻辑。
前置基线：`docs/plans/2026-10-25-moye-ui-modernization.md` 的 Stage 1（浅桃 + 玻璃 + 头像）。

## 1. 现在为什么“死板”

对照你发的截图和实际窗口：

| 问题 | 现在 |
|---|---|
| 模块被横线切开 | 标题栏底边一条线、菜单栏底边一条线、工具栏底边一条线，三块像三个抽屉 |
| 工具栏被竖线切碎 | 历史/工具/粗细/颜色/动作之间靠 1px 竖线分隔，每段都像独立格子 |
| 所有行一样宽 | 标题、菜单、工具栏都从左贴到右，缺少内外边距和层级 |
| 没有“面”的概念 | 只有线和按钮，缺少一块完整的材质；半透明也没有承载物 |
| 控件密度一样 | 工具、粗细、颜色、动作视觉重量相同，没有主次 |
| 窗口边缘太硬 | 内容区直接顶着工具栏，没有呼吸和层次 |

苹果的做法不是“加更多线”，而是反过来：
**一块连续材质 + 少量分组 + 大间距 + 只在必须的地方画线。**

## 2. 三个 Apple 式方向

### 方向 A：统一玻璃顶栏（推荐）

**一块圆角玻璃面板**包住标题、标签、菜单、工具栏，三行之间不再画横线，靠 6–10px 留白分组。工具栏内部用四到五个“透明分组胶囊”，不再用竖线。

- 视觉：像 macOS 的 Notes / Freeform 顶部区域，一整块材质，内容从下面自然开始。
- 改动：主窗顶栏容器、QSS、少量布局边距；控件顺序不变。
- 垂直空间：比现在多约 8–12px（面板外边距 + 行间距），但换来整体感。
- 适合：既想苹果感，又不想改变工具位置。

### 方向 B：浮动条（更轻）

标题栏是一块浮动玻璃条，工具栏是另一块浮动胶囊，两块之间留 8px 空气；菜单收进标题栏左侧或折叠为“菜单”。

- 视觉：更空、更像 iPad / Final Cut 的浮动控制条。
- 代价：标题、标签、菜单、工具栏会分家，模块感可能比 A 更强；垂直空间也多。
- 适合：内容优先、愿意牺牲一点紧凑。

### 方向 C：内容优先（最激进）

默认只保留一条极简标题栏，工具栏在鼠标靠近顶部时淡入；菜单收进一个按钮。

- 视觉：最像“看内容”的苹果应用。
- 代价：改变了现有“工具常驻”的习惯；不建议第一版。

**推荐 A。** 它解决“模块被线切开”，又不改变你的操作路径。

## 3. 推荐布局

```
┌──────────────────────── 窗口 ────────────────────────┐
│  ┌────────────── 一整块玻璃顶栏（圆角 16）──────────┐  │
│  │ (头像) 墨页   [笔记 1] [+]                       │  │
│  │ 文件  编辑  视图  导航  工具  帮助                │  │  ← 无底线
│  │ [撤销 重做] [工具组] [粗细] [颜色组] [动作组]      │  │  ← 无竖线
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  内容区（PDF / 草稿 / 笔记）                            │
│                                                        │
│  ┌──────────── 浮动状态胶囊 ────────────┐              │
│  │ 已打开 sample.pdf     已保存  1/10 100% │              │
│  └──────────────────────────────────────┘              │
└────────────────────────────────────────────────────────┘
```

关键：
- 顶栏是**一块**：标题栏、菜单、工具栏共享同一个玻璃底，不再各自铺底。
- 三行之间没有横线；只用 **6/8px 留白**和字重区分。
- 工具栏不再插竖线；用 **8px 空白 + 分组胶囊**。
- 内容区与顶栏之间没有分隔线；用顶栏圆角、阴影和 8px 间隙分开。
- 状态栏变成底部浮动胶囊，不贴满整宽，不再有顶部横线。

## 4. 具体做法

### 4.1 顶栏容器

- 新增 `TopChrome(QFrame)` 包住 titlebar + menubar + toolbar：
  - 外边距：左右 8px、上 8px、下 8px。
  - 背景：`rgba(255, 252, 253, 0.58)`。
  - 边框：1px `rgba(255,255,255,0.55)` + 1px 外描边 `rgba(236,171,195,0.45)`。
  - 圆角：16px。
  - 阴影：一个很轻的投影（`QGraphicsDropShadowEffect`，blur 22、alpha 45），只加在顶栏这一块，不给每个按钮加。
  - 内部：`QVBoxLayout`，三行间距 4px，行内左右 10px。
- 标题栏：透明底、无底线；标签仍是白色书签，当前页有轻阴影。
- 菜单栏：透明底、无底线；菜单项 12px，hover 为浅桃胶囊；不再画整条底边。
- 工具栏：透明底、无边框；不再单独铺白卡。

> 如果顶栏圆角 + 阴影在无边框窗口上出现裁切，退一步：保留圆角、去掉阴影，不退回横线。

### 4.2 工具栏分组（去掉竖线）

控件顺序不变，只把连续的控件包进 4–5 个透明胶囊：

1. **历史**：撤销 / 重做，一个窄胶囊。
2. **工具**：钢笔 / 荧光笔 / 鼠标 / 笔记 / 文字 / 橡皮 / 全屏批注，一个胶囊；选中项浅桃底 + 陶土描边。
3. **粗细**：四档圆点 + 滑杆 + 数字，一个胶囊；数字用 tabular。
4. **颜色**：9 色 + 取色器 + 当前色，一个胶囊；白/浅色块加细边。
5. **动作**：图片 / 截图 / 查找 / 清空 / 草稿纸 / 分屏 / 设置，按功能再拆成 2 个胶囊。

胶囊本身：
- 背景 `rgba(255,255,255,0.34)`，圆角 10px，内边距 3px。
- 不画描边；靠底色和 8px 间距分组。
- hover 只提亮胶囊，不整条工具栏变色。
- 去掉现有 `QFrame#Sep` 竖线；分隔线只在弹窗/输入框等需要边界的地方保留。

### 4.3 菜单与标签

- 菜单：与顶栏同材质；去掉菜单栏底边；菜单项 6px 圆角，选中浅桃底。
- 标签：当前页白底 + 细边 + 轻阴影；非当前页透明；关闭键 hover 才出现；未保存圆点用琥珀色。
- 标题栏左侧：24px 圆形头像 + 13px/600「墨页」；头像不参与拖动以外的逻辑。
- 窗口按钮：保留现有位置（置顶/最小化/最大化/关闭），hover 用 8px 圆形底；右侧不再被一条横线托着。

### 4.4 状态栏

- `QStatusBar` 背景透明、去掉 top border。
- 内部放一个浮动状态胶囊：左右 12px 边距、圆角 12px、半透明白、轻边框。
- 左消息 + 右侧数据 chip 保留；chip 之间只用 6px 间距，不再画竖线。
- 窗口底部留 6px 透明空气。

### 4.5 内容区

- 去掉工具栏与内容之间的硬边；内容直接接在顶栏下方，顶栏阴影自然落在内容上。
- PDF 保持 fit-width，不加左右灰边；草稿画布暂时保持深色（保护旧墨迹）。
- 侧栏（目录/缩略图）改成独立玻璃卡，与内容区留 6px 间隙；不要贴死在工具栏下面。

### 4.6 材质与光影

- 只有两层材质：
  1. 窗底：浅桃渐变 + 柔光斑 + 2–3 片淡花瓣（已有）。
  2. 顶栏/浮层：半透明白玻璃 + 1px 高光边。
- 不再给每个小控件加背景/边框；按钮只在 hover/选中时出现底色。
- 阴影只给三处：顶栏、状态胶囊、打开的弹层。不给每个按钮、每个分隔线加阴影。
- 透明为自绘玻璃（透出桃色渐变），不做系统桌面 Acrylic；真 Acrylic 会影响手写/滚动帧率。

### 4.7 颜色与字体

- 沿用当前浅桃 token：`SHELL #FFE9F1`、`SURFACE #FFFCFD`、`ACCENT #A84E35`、`TEXT #4B2F38`。
- 不再用高饱和色；强调色只出现在选中态和焦点环。
- 字体：`Microsoft YaHei UI` / `Segoe UI`；标题 13/600，菜单 12/400，控件 12/500，数字 tabular。
- 圆角：顶栏 16、胶囊 10、标签 8、弹层 12–14。

## 5. 实施拆分

### Stage A：统一顶栏（先做，视觉变化最大）

- 新增 `TopChrome` 容器；把 titlebar/menubar/toolbar 收进去。
- 去掉 titlebar/menubar/toolbar/status 的四条横线；去掉工具栏竖线。
- 顶栏玻璃底 + 圆角 + 轻阴影；行间距 4px。
- 状态栏浮动胶囊。
- 验收截图：1100、900、792 宽；100%/150%；空态、草稿、PDF。

### Stage B：工具栏分组胶囊

- 在 `Toolbox` 内把 blocks 包成 4–5 个 `QFrame#ToolGroup`；顺序与可见性不变。
- 选中态、hover、颜色块、粗细 chip 统一。
- 保持 40px 高度；792px 下全屏批注按钮仍在可见区。

### Stage C：菜单/标签/弹层细节

- 菜单 hover、标签书签、窗口按钮圆形 hover。
- 设置、查找、最近、关闭确认统一玻璃材质。
- 笔记卡 / 独立窗口的边框降级，只保留一层边。

### Stage D：可选浅色草稿画布

- 如果要 Apple Notes 那种浅色纸面，再单独处理“浅色墨迹自动转深色”；这涉及落笔颜色逻辑，不放在纯样式阶段。

## 6. 验收

- 不带任何横向分割线的前提下，标题/菜单/工具栏仍能一眼分区。
- 792px 窄窗：全屏批注、截图、设置仍可用（批注已在工具组左侧，设置可滚动或菜单可达）。
- 150%：圆角、1px 高光边、阴影不糊、不裁切。
- 文字对比度 AA；玻璃底上的深可可文字不因透明度下降。
- 现有 UI/布局/快捷键测试通过；控件顺序、数量、可见性不变。
- 主任务路径不变：打开 PDF、写字、荧光笔、橡皮、笔记、查找、设置、导出。
- 真实截图：空态、PDF、草稿、设置、笔记、全屏批注；程序抓取，不操控鼠标。

## 7. 风险

| 风险 | 对策 |
|---|---|
| 顶栏圆角/阴影被无边框窗口裁切 | 先圆角后阴影；阴影失败就只保留圆角和间距 |
| 菜单/工具栏去掉线后分不清 | 用 8px 间距 + 胶囊底色 + 字重；截图实测再调 |
| 玻璃透明导致文字对比下降 | 文字永远深可可；玻璃 alpha 不低于 0.4 |
| 顶栏变高挤压内容 | 外边距控制在 8px、行距 4px；总增加不超过 12px |
| 标题栏拖动热区被新容器挡住 | TopChrome 不拦截鼠标；拖动仍由 TitleBar 处理 |
| 工具栏 792px 溢出 | 保持横向滚动；全屏批注在工具组内，设置仍可从菜单/Ctrl+, 进入 |
| QSS 级联误伤弹窗 | 继续按 objectName 限定；不写全局 QDialog |

## 8. 建议

先做 **方向 A 的 Stage A**：只统一顶栏和去掉横线，不动按钮位置与功能。做完给你看 1100 / 792 两张对比图；如果模块感消失、层级清楚，再做工具栏胶囊和弹层。

如果你要更“苹果”，可以在 A 和 B 之间选：
- A：一块连续玻璃顶栏（推荐，紧凑）。
- B：标题栏和工具栏两块浮动玻璃条（更空，但模块感更强）。
- C：内容优先、工具栏自动淡入（改动最大）。

我建议先按 A 做，不满意再往 B 调。
