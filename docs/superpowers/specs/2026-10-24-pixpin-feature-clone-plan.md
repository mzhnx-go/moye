# PixPin 功能复刻实施方案

> 日期：2026-10-24
> 目标：把 PageFlow 的截图从“框选后进剪贴板”升级成 PixPin 式截图工作流
> 状态：**P0（S1–S14）已实现并回归；P1 未开始**
> 调研来源：PixPin 官网 https://pixpin.cn/ 、第三方使用教程（见文末证据表）

## 0. P0 落地结果（2026-10-24）

新增 `sketchpad/screenshot/`：

| 文件 | 内容 |
|---|---|
| `capture.py` | 区域/窗口/全屏/上一区域/取色 的抓屏与 HiDPI/多屏换算 |
| `editor.py` / `scene.py` / `items.py` / `toolbar.py` | 截图编辑器：矩形/椭圆/箭头/画笔/马克笔/文字/序号/马赛克/模糊/裁剪、撤销重做、复制/保存/贴图/OCR |
| `pin.py` | 置顶贴图窗口：移动/缩放/旋转/透明度/右键菜单/双击关闭 |
| `history.py` / `history_ui.py` | PNG + JSON 历史（默认 100 条/30 天）与列表窗口 |
| `ocr.py` | Standard 复用 RapidOCR；Lite 不显示 OCR |
| `controller.py` | 主窗/批注层暂隐恢复、模式分派、贴图管理、历史入口 |

入口：工具栏相机（主按钮=区域，箭头菜单=窗口/全屏/上一区域/取色/历史）、
全局 `Alt+A→S`、工具菜单「截图」、托盘「截图（区域）」「截图历史…」。
框选松手直接进编辑器；原图先复制到剪贴板，编辑器里的复制会覆盖为标注后的图。
上一区域会持久化到 `data/screenshots/last_region.json`，重启后仍可用。

回归：全量 **1325 passed / 6 skipped**（1331 collected，6 项为既有关闭确认 skip）；
改动后新增的 6 项截图测试在对应文件单独复跑通过，当前合计 **1331 passed**。
真机副屏（150% DPI）用编辑器/贴图窗口抓图检查过布局与渲染，并验证了
“主窗隐藏 → 编辑器 → 关闭恢复”和截图历史落盘。


## 1. 结论（先做哪一半）

PixPin 的功能面很宽，不建议一次全抄。按“截完图之后最常用的动作”排序，先做一个 **6 件套**：

1. 框选后进入**截图编辑器**，而不是直接复制。
2. 编辑器工具：矩形、椭圆、箭头、画笔、马克笔、文字、序号、马赛克、模糊、裁剪。
3. **复制 / 保存 / 钉在屏幕上（贴图）**。
4. **OCR 取字**（复用 Standard 已有的 RapidOCR，不新增外部安装）。
5. **截图历史**（可重新编辑/复制/贴图）。
6. **取色器**（屏幕取色，复制 HEX/RGB）。

第二批再做：长截图、GIF/录屏、窗口/全屏/上一区域等截图模式、完整快捷键与设置页。
第三批（可选）：OCR 翻译/表格识别、多贴图管理、标注模板。

## 3. PageFlow 现状与缺口

### 已有

- `sketchpad/annotate/capture.py`：区域框选、PixPin 式「复制/保存/取消」工具条、高 DPI/多屏裁剪。
- 截图只进剪贴板（用户明确要求，不自动插入笔记）。
- 全屏批注层：钢笔、橡皮、颜色、粗细、撤销、清空、穿透、横竖排、`Alt+1..4` 工具键。
- Standard 转换中心已有 RapidOCR，可复用来做截图 OCR。
- 已有无边框窗口/贴图式窗口的外壳经验（笔记窗口）。

### 缺口

- 没有截图编辑器：选完只能复制/保存，不能画框、箭头、文字、打码。
- 没有贴图（把截图钉在屏幕上）。
- 没有 OCR 取字入口。
- 没有截图历史。
- 没有长截图、录屏/GIF。
- 没有取色器。
- 截图方式只有区域框选，没有窗口/全屏/上一区域。

## 5. 交互方案

### 5.1 截图主流程

```
工具栏相机 / Alt+A→S
   ↓
主窗隐藏，出现全屏框选
   ↓
拖出选区（尺寸、放大镜、手柄可调）
   ↓
松开 → 选区旁出现工具条：
  [矩形][椭圆][箭头][画笔][马克笔][文字][序号][马赛克][模糊][裁剪]
  [撤销][重做] | [复制][保存][贴图][OCR][取消]
   ↓
复制/保存/贴图/OCR 后结束；Esc 取消
```

- 选区仍可拖动/缩放；点击工具后在选区内画。
- 编辑期间原截图保留，导出时把所有标注合成到副本（非破坏）。
- 双击选区 = 复制；`Enter` = 复制；`Ctrl+S` = 保存；`Esc` = 取消。

### 5.2 贴图窗口

- 新建无边框、置顶、可拖动的 `PinWindow`；样式与笔记独立窗口一致。
- 鼠标拖动移动；滚轮缩放（或右下角手柄）；右键菜单：复制/另存/旋转/透明度/关闭。
- 默认贴到当前鼠标位置右侧，不抢焦点；支持多张同时存在。

### 5.3 截图历史

- 入口：主工具栏相机下拉、工具菜单「截图历史」、截图编辑器「历史」。
- 存储：`data/screenshots/<yyyyMMdd>/<uuid>.png` + `history.json`（原始图、缩略图、时间、来源窗口）。
- 默认保留最近 100 条 / 30 天，超出按时间清理；设置里可改。
- 历史条目操作：复制、贴图、重新编辑、删除。

### 5.4 OCR

- 编辑器工具条「OCR」：识别选区（无选区则整图），结果弹出只读文本框，支持全选复制。
- 只在 Standard 显示 OCR 按钮（Lite 不加载 RapidOCR）。
- 复用 `rapidocr_onnxruntime`，不新增安装；识别失败给明确错误。

### 5.5 长截图（P1）

- 先做“手动滚动”模式：框选后固定选区，用户滚动页面，程序按固定间隔抓帧，按重叠区域匹配拼接。
- 自动滚动模式需要向目标窗口发送滚轮/按键，风险高，放到后续；在 PageFlow 自己打开的 PDF 中可优先实现“自动滚动拼接”。

## 6. 技术方案

### 6.1 模块拆分

```
sketchpad/screenshot/
  capture.py       区域/窗口/全屏/上一区域；选区手柄、放大镜、取色
  editor.py        截图编辑器（背景图 + 编辑层 + 工具条 + 动作）
  scene.py         QGraphicsScene：图片背景 + 标注 item + 撤销栈
  items.py         矩形/椭圆/箭头/文字/序号/马赛克/模糊 item
  pin.py           PinWindow（置顶贴图窗口）
  history.py       历史记录存储/清理/缩略图
  ocr.py           RapidOCR 适配（Standard 注入）
  longshot.py      长截图拼接（P1）
  record.py        GIF 录制（P1）
  toolbar.py       截图编辑器工具条
```

- `sketchpad/annotate` 继续负责“全屏批注层”（屏幕手写），不与截图编辑器混在一起；两者可共用笔迹/颜色/命令模型。
- 截图编辑器使用 `QGraphicsScene`，坐标就是截图像素；导出用 `QPainter` 把标注合成到原图，保证复制/保存一致。
- OCR 通过 Standard 入口注册（类似 word/convert），Lite 不 import。
- 历史/贴图/编辑器为共享功能，Lite 也可用（只要不依赖 OCR/录屏依赖）。

### 6.2 与现有入口的衔接

- 主工具栏相机按钮、工具菜单「截图」、`Alt+A→S` 都进入新编辑器。
- 现有「全屏批注层」保持不变；它的相机按钮也进入同一个截图编辑器。
- 设置新增「截图」页：保存目录、默认格式、截图后是否复制、历史保留数量、截图快捷键、贴图热键。
- 全屏批注层的 `Alt+1..4` 不受影响。

### 6.3 数据与安全

- 截图默认只进剪贴板 + 历史（可设置关闭历史）。
- 保存/历史都写用户数据目录，不写 PDF 旁边。
- 不自动上传、不联网；OCR 在本机运行。
- 贴图窗口只显示图片，不留可执行内容。

## 7. 分阶段实施

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0-1 | 选区手柄/放大镜/取色 + 编辑器框架 | 截图后可编辑、可取消、可复制 |
| P0-2 | 形状/画笔/文字/序号/马赛克/模糊/裁剪 + 撤销 | 每种工具画完能撤销、复制图与预览一致 |
| P0-3 | 贴图窗口 + 历史记录 | 贴图可移动/缩放/关闭；历史可复制/重开 |
| P0-4 | OCR 适配（Standard）+ 设置页 | 中文/英文截图可识别并复制；Lite 无 OCR 按钮 |
| P1-1 | 长截图（手动滚动） | 两屏重叠拼接无明显断层 |
| P1-2 | GIF 录屏 | 选区录制可导出 GIF，可取消 |
| P2 | 多贴图管理/翻译等 | 按需 |

每个阶段单独提交、单独回归；P0 完成前不改全屏批注层的行为。

## 8. 测试与验收

- 离屏测试：选区/手柄/工具切换/撤销/裁剪/导出像素、历史读写、贴图窗口几何、OCR fake 适配。
- 真机验收（必须在 Windows 实机）：
  1. 150% 副屏框选与导出像素正确；
  2. 贴图窗口置顶、拖到副屏、缩放/透明度；
  3. OCR 中文/英文截图；
  4. 长截图手动滚动拼接；
  5. 全屏批注层 `Alt+1..4` 不受影响。
- 不在 offscreen 里验证低层输入注入/长截图滚动，需真机；不能把“离屏通过”当“功能可用”。

## 9. 风险与取舍

- **不要一次全抄**：标注工具 + 贴图 + OCR + 历史是核心；长截图/GIF 单独排期。
- **长截图需要模拟滚动**：可能影响其他应用，优先手动滚动/仅 PageFlow 内文档。
- **GIF 体积大**：默认 10–15fps、限制时长；MP4 需要 ffmpeg，破坏零安装，暂不做。
- **OCR 只进 Standard**：RapidOCR 体积/依赖不塞进 Lite。
- **贴图窗口层级**：置顶窗口可能挡住用户操作，默认不抢焦点，提供一键关闭全部。
- **历史磁盘占用**：默认 100 条/30 天，设置可改；删除前不弹确认可撤销？
