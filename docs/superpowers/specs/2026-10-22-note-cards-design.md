# PDF 页内手写笔记卡片设计（2026-10-22）

## 1. 目标

把 SketchPad 从“PDF 批注”扩展为“笔记 + 资料阅读”的合体：

- 在 PDF 任意页的任意位置放一个笔记图标；
- 点图标，像思维导图节点一样从图标位置展开一张带横线的手写笔记卡片；
- 卡片可收回、放大/还原，支持深色/浅色两种纸面；
- 笔记卡片自带工具栏，和 PDF 主工具栏各管各的；
- 笔记跟 PDF 一起保存，导出 PDF 时作为额外页插在锚点页后面。

不在本期范围：卡片自由拖拽/四角缩放、文字输入、笔记全文检索、数据库、跨页笔记。

## 2. 已确认的决策

| 决策点 | 结论 |
|---|---|
| 纸面 | 每张卡片可切深色/浅色纸 |
| 工具 | 卡片自带紧凑工具栏（画笔/橡皮/颜色/粗细/撤销/重做/清空/换纸/放大/关闭/删除）；主工具栏只控制 PDF |
| 键盘 | 按焦点分流：焦点在卡片内时 `B/Q/1-4/Ctrl+Z/Y/清屏键` 控制笔记；焦点在主界面时控制 PDF |
| 存储 | 扩展 `.sketch.json` 的 `notes` 字段；有笔记时 sidecar 版本升到 2 |
| 导出 | 在锚点页后依次插入该页的笔记页 |
| 卡片尺寸 | 设计尺寸 560×720；点图标动画展开；可放大到视口约 80%，内容和横线一起缩放 |
| 同时打开 | 同一时间只开一张卡片；换开另一张先保存当前笔记 |
| 遮罩 | 卡片打开时用遮罩挡住 PDF 输入，避免误画到 PDF |

## 3. 数据模型与存储

### 3.1 JSON

```json
{
  "version": 2,
  "pages": [
    {
      "w": 595.0,
      "h": 842.0,
      "r": 0,
      "strokes": [],
      "notes": [
        {
          "id": "n-1",
          "x": 320.0,
          "y": 410.0,
          "w": 560.0,
          "h": 720.0,
          "paper": "dark",
          "strokes": [
            {"p": [[10.0, 20.0], [30.0, 40.0]], "c": "#e8eaed", "w": 2.0, "t": "pen"}
          ]
        }
      ]
    }
  ]
}
```

- `x/y`：锚点，页面显示坐标（PDF 点），图标尖端/中心落在该点；
- `w/h`：卡片设计尺寸；当前固定 560×720，后续可扩展；
- `paper`：`"dark"` / `"light"`；
- `strokes`：笔记内容，坐标是**卡片设计坐标**（0..w / 0..h），复用现有 `Stroke`；
- `id`：页内唯一字符串；新建时用时间戳/序号，避免重名；
- `notes` 缺省为空数组；v1 文件读入时视为空。

### 3.2 版本与兼容

- `FORMAT_VERSION = 2`；`from_json` 接受 v1 和 v2；
- 有笔记时 `to_json` 写 v2；没有任何笔记时仍写 v1，旧稳定版可以继续打开（减少不必要的拒绝）；
- 旧稳定版读到 v2 会走 `PdfVersionTooNew`，拒绝打开 sidecar，而不是静默丢掉 notes；
- 因此**使用笔记功能前必须先重建稳定包**，避免旧包保存时丢笔记。

### 3.3 模型

- `Note` dataclass：`id/x/y/w/h/paper/strokes`；
- `Page.notes: list[Note]`；
- `Note` 的笔迹复用 `Stroke`；笔记画布有独立 `History`，撤销不污染 PDF 页历史；
- 新建/删除笔记作为页级操作直接改模型并标记 dirty；笔记内容修改走自动暂存。

## 4. 界面与交互

### 4.1 放置图标

- 新工具「插入笔记」：工具栏图标 + 工具菜单 + 快捷键 `N`（文档模式）；
- 选中后鼠标在 PDF 页上变成笔记图标的预览；点击页面任意位置创建笔记；
- 锚点钳在页面矩形内；同页可放多个；
- 图标：约 24px 的圆角便签/折角图标，带页内序号；不随 PDF 缩放变大变小，始终可点；
- 图标点击：展开对应卡片；已有卡片展开时先保存并收起旧的。

### 4.2 卡片

- 覆盖层：卡片与半透明遮罩挂在视图栈（PDF 区域）之上，不遮标题栏/主工具栏/状态栏；
- 展开：从图标的屏幕位置动画到设计尺寸（约 180–220ms，geometry + 淡入）；
- 收起：反向动画；点遮罩、关闭键或再次点图标均可收起；
- 放大/还原：在基础尺寸与视口约 80% 之间切换，卡片按比例缩放，笔记内容和横线一起缩放；
- 卡片头部/工具栏：
  - 第一组：画笔、橡皮、颜色、粗细；
  - 第二组：撤销、重做、清空；
  - 右侧：深/浅纸切换、放大/还原、删除笔记、关闭；
  - 图标风格沿用现有纯图标工具栏，按钮 `NoFocus`；
- 纸面：
  - 深色纸：深灰底 + 更浅的横线，默认浅色笔；
  - 浅色纸：米白底 + 暖灰横线，切到浅纸时如果当前笔色太浅，自动换深色默认笔；
  - 横线固定 28 设计单位间距，左侧页边线；
- 卡片打开时遮罩拦截 PDF 的鼠标/滚轮输入。

### 4.3 键盘与焦点

- 卡片打开后把焦点交给笔记画布；
- 应用级按键过滤在焦点属于卡片时放行给卡片：`B/Q/1-4/Ctrl+Z/Y/清屏键` 作用于笔记；
- 焦点回到主界面时恢复控制 PDF；
- 主工具栏的垃圾桶/撤销仍只控制 PDF；卡片工具栏的垃圾桶只清空笔记内容（不删除卡片本身，删除卡片用头部删除键）。

## 5. 笔记画布

- 复用 `Stroke`、`_stroke_path`、`_make_pen`/`_stroke_pen`、抬笔平滑、`History`；
- 设计坐标系 560×720；画布按卡片内容区等比缩放/居中，横线与笔迹一起缩放；
- 支持画笔、橡皮（整条删除）、清空、撤销/重做；
- 笔记纸面的横线在场景背景层绘制，不进入笔迹数据；
- 笔迹在抬笔时按当前平滑设置处理；笔记颜色/粗细由卡片工具栏控制，与 PDF 状态独立；
- 卡片关闭/切换文档/退出前把笔记笔迹收口到模型并触发自动暂存；
- 删除卡片：头部删除键先弹确认（“删除这张笔记卡片及全部内容？”），确认后移除笔记与图标并标记 dirty；不进入 PDF 页历史。

## 6. 导出

- 扩展导出路径为“按原页序重建 PDF”：
  1. 对每个原页：复制原页、画该页 PDF 笔迹；
  2. 若该页有笔记：在页上画出小笔记标记（带序号，可选）；
  3. 在该页后依次插入笔记页；
- 笔记页尺寸：宽度取锚点页宽度，高度按卡片设计比例（720/560）换算；
- 笔记页内容：纸面底色 + 横线/页边线 + 笔记笔迹（按卡片设计坐标缩放到笔记页）；
- 深色纸导出为深色页、浅色纸导出为浅色页，保持笔迹颜色可读；
- 原 PDF 文件只读，导出文件另存；导出页数会增加；
- 现有“不能覆盖原文件”的守门规则保持不变。

## 7. 边界与错误处理

- 锚点越界/NaN：拒绝或钳回页内；
- note 字段缺省/坏条目：按现有 sidecar 严格解析规则报错，错误信息带页号/笔记号；
- 笔记 id 冲突：打开时按页内 id 去重，保留首个并给出提示；
- 卡片的位置超出视口：展开时钳在视口内；
- 切换 PDF/回草稿/退出：先收起并保存当前卡片；文档已关时不再访问卡片画布；
- 旧稳定版：v2 sidecar 拒绝打开，提示用新版；不静默丢数据。

## 8. 测试与验收

### 8.1 自动化

- `pdfstore`：v1 读入、v2 读写、notes 缺省、坏字段报错、版本闸门；
- 笔记模型：新建/删除/内容变更、id 唯一、坐标钳制；
- 离屏 UI：放置图标、展开/收起、放大/还原、深/浅纸切换、画/擦/撤销/清空、焦点键盘分流、关闭重开、删除确认；
- 工具隔离：卡片工具栏清空不影响 PDF 页；主工具栏垃圾桶不影响笔记；
- 导出：原页序保持、笔记页插在锚点页后、页数增加、笔记笔迹落位、原 PDF 哈希不变；
- 像素：深/浅纸横线、卡片外框、遮罩不吞卡片；
- 全量回归。

### 8.2 手动验收

1. 打开讲义，按 `N` 在页脚空白处落图标；
2. 点图标展开，写几笔、擦一笔、撤销、切换深/浅纸；
3. 放大到 80% 再还原；收起再展开，内容仍在；
4. 焦点在卡片内按 `B/Q/1-4/Ctrl+Z` 只影响笔记；点主工具栏垃圾桶只清 PDF 页；
5. 导出 PDF：锚点页后出现笔记页，内容与卡片一致，原文件不变；
6. 用旧稳定版打开带笔记的 sidecar：应拒绝而不是丢笔记。

## 9. 实现拆分（建议）

1. 模型 + sidecar v2 + 导出数据接口（含测试）；
2. 卡片画布 + 纸面 + 卡片工具栏（离屏可测）；
3. 图标放置 + 覆盖层展开/遮罩 + 焦点路由 + 自动暂存；
4. 导出笔记页；
5. 文档、全量回归、打包。

数据层/导出和 UI 层可以并行；`PdfView`/`app.py` 是共享文件，UI 接线串行。
