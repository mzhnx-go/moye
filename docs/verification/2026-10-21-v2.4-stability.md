## 3. 旋转页换算（按 §4.1 口径）

- 200×300 页、90°：未旋转命中 `(50, 47.1)-(79.35, 63.59)`，乘
  `page.rotation_matrix` 后为 `(236.41, 50.0)-(252.90, 79.35)`，落在 300×200
  显示页框内；180/270 同样断言。
- 导出：在**显示坐标**的文字位置落笔，导出后 `get_drawings()` 的 rect 回到
  未旋转文字 bbox 上；0° 页导出结果与旧实现逐值一致。
- 单点笔迹只换算圆心，直径保持 6pt。
- `Page.rotation` 写进 sidecar 的 `r`；不做旧 sidecar 迁移。

## 4. 自动暂存语义（本批改动）

| 动作 | 磁盘结果 |
|---|---|
| 停笔 2 秒 | 写 `data/autosave/<sha1>.json`（信封含 pdf/saved_at/document），**不碰 sidecar** |
| Ctrl+S | 写 sidecar、清缓存、停 debounce |
| 切换文档 / 关文档 / 退出 | 有未提交批注 → 问「保存 / 放弃 / 取消」；保存则写 sidecar + 清缓存 |
| 强杀后再次打开同一 PDF | 检测到缓存 → 问是否恢复；拒绝则删缓存 |
| 坏 sidecar | 问是否忽略批注打开；同意则先改名为 `.sketch.json.corrupt-时间` |

默认值：`pdf_autosave` 默认开；配置里显式 `false` 仍保持关。
