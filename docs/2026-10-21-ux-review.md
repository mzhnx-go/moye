# SketchPad 体验与界面评审

> 版本基线：v2.3（提交 `7567ebf`，全量测试 375 passed）
> 评审日期：2026-10-21
> 评审范围：桌面端两种模式（草稿 / PDF 批注）的用户旅程、快捷键、布局、视觉一致性、功能扩展
> **本文件只做规划，未修改任何代码。** 技术性缺陷的逐项修法仍以根目录 `TODO.md` 为准，本文不重复展开。

---

## 0. 摘要

项目在功能完整度和工程约束上已经不错：双模式、侧栏、查找、最近打开、sidecar、自动保存、草稿纸浮窗、托盘、全局热键都有，375 条测试全绿。问题主要集中在**“用户第一次用是否顺手”**和**“长时间用是否不丢东西、不迷路”**这两件事上。

最值得优先处理的 8 件事：

1. **打开 PDF 停在页面中部**，标题和页首内容被切掉（实测）。
2. **窗口标题永远是 “SketchPad”**，不显示文件名、页码、是否有未保存批注。
3. **深色主题不完整**：目录树是白底、滚动条是白色、跳页对话框是浅色，形成“白色孤岛”。
4. **单键快捷键依赖画布焦点**：点过目录、缩略图或查找框后，`B/Q/E/1–4` 全部失灵。
5. **查找条清空后高亮残留**；当前命中只靠填充色深浅区分，多个命中时不够醒目。
6. **菜单存在重复项与死项**：“清空本页”和“清屏”重复；“页面”菜单只有一个永远置灰的条目。
7. **缺少应用图标**：任务栏、标题栏、托盘都没有身份标识。
8. **帮助里的快捷键表是手写常量**，已经和实际绑定漂移（缺 `Ctrl+,`、`F11`、`F3`、`Ctrl+0` 等）。

功能上，最值得加的不是“更多工具”，而是**高亮笔、页面书签/续读、导出当前页 PNG、夜间阅读、全屏阅读模式、拖放打开**。这些直接对应“上课批注讲义”和“课后复习”两个主场景。

## 2. 用户与场景

### 2.1 目标用户

| 维度 | 描述 |
|---|---|
| 身份 | 学生 / 自学者 / 需要看讲义和扫描资料的人 |
| 设备 | Windows 11 笔记本或台式机，鼠标 + 键盘；部分人用数位板或触控板 |
| 使用姿势 | 桌面长时间坐着用，不是移动端碎片时间 |
| 核心诉求 | 在 PDF 上快速写写画画；下次打开还能接着看；不丢批注 |
| 非诉求 | 云同步、协作、OCR、复杂排版、专业绘图 |

### 2.2 三个主场景

**场景 A：课前 10 分钟快速打开讲义**
期望：双击或拖入 PDF → 立刻看到第一页标题 → 直接翻到老师说的页码 → 开始写。
现状摩擦：打开后停在页面中部；不知道当前文件叫什么；没有“上次看到第几页”。

**场景 B：课中连续批注**
期望：一支笔、一个荧光笔、橡皮、翻页、缩放，全键盘可完成，不用低头找按钮。
现状摩擦：没有荧光笔；点过缩略图后 `B/Q` 失灵；清屏键 `E` 紧邻画笔键，误触后虽然可撤销，但没有反馈。

**场景 C：课后复习**
期望：快速跳到“有批注的页”；按书签回到重点；把某一页导出成图片发给同学；晚上看时不刺眼。
现状摩擦：没有“有批注的页”入口；没有书签；只能导出整份 PDF；没有夜间模式。

### 2.3 成功标准（用户语言）

- 第一次打开，**10 秒内**知道“这里可以打开 PDF、也可以直接写”。
- 任何时候都知道**当前文件是什么、在第几页、批注有没有保存**。
- 手不离开键盘也能完成 80% 的批注动作。
- 关窗口、换文件、退出程序，**不会静默丢批注**。

### 3.1 新发现的确定性问题（未在 TODO 中）

#### A. 打开 PDF 停在页面中部（P0）

- 现象：打开任意 PDF，首屏看不到页首标题，直接从正文中间开始（截图复现）。
- 根因：`PdfView.open()` 先把滚动条归零，再调用 `fit_width()`；而 `fit_width()` 为了“缩放后不漂移”，把**缩放前的视口中心**钉住（`sketchpad/ui/pdfview.py:192-217`、`:341-366`）。缩放前中心已经在页面中部，缩放后自然停在中间。
- 建议：打开流程单独走“定位到页首”的分支：`fit_width()` 后 `verticalScrollBar().setValue(0)`，或 `centerOn(page_top_center)`。翻页/缩放仍保留现有锚点逻辑。
- 验收：任意竖版 PDF 打开后，页首 24pt 内可见；横版页左右居中、顶部对齐。

#### B. 目录树与滚动条是浅色（P0）

- 现象：深色应用里，目录树是白底黑字，滚动条是白色，跳页对话框是浅色。
- 根因：`TocPanel` 没有应用任何 QSS（`sketchpad/ui/toc_panel.py:17-51`）；`theme.QSS` 也没有 `QTreeWidget`、`QScrollBar`、`QDialog` 的深色规则（`sketchpad/ui/theme.py:20-114`）；`QInputDialog` 走系统浅色。
- 建议：
  1. 给 `TocPanel` 增加与 `ThumbPanel` 同款的 `_apply_style()`；
  2. 在 `theme.py` 增加 `QScrollBar:vertical/horizontal` 深色规则；
  3. 用“状态栏内联页码输入”替代 `QInputDialog`（同时解决 Ctrl+G 模态框慢的问题），或单独给跳页对话框套深色 QSS。
- 验收：深色模式下，目录、缩略图、滚动条、跳页输入没有白色大面积区域。

#### C. 标题栏不带文件名与状态（P0）

- 现象：无论打开哪份 PDF，标题始终是 `SketchPad`（`sketchpad/app.py:112`），自绘标题栏也只显示这个常量。
- 影响：多份讲义来回切时，用户无法确认当前文件；也不知道有没有未保存内容。
- 建议标题格式：`lecture03.pdf — SketchPad`，右侧或状态栏再加 `3/26 · ●`（● 表示有未保存批注）。
- 落点：`_enter_document` / `_enter_draft` / 保存成功 / 撤销回退时统一调用一个 `_refresh_title()`。

#### D. 单键快捷键只认画布焦点（P0）

- 现象：点一下目录、缩略图或查找框，再按 `B/Q/E/1–4` 没反应。
- 根因：这些键在 `SketchView.keyPressEvent` 与 `PdfView.keyPressEvent` 里处理（`sketchpad/ui/canvas.py:252-285`、`sketchpad/ui/pdfview.py:589-613`），不是窗口级 QShortcut。
- 这是有意的取舍（避免在查找框里打 `B` 被抢），但副作用太大。
- 建议：改为窗口级 QShortcut + 文本输入保护：
  - 当 `QApplication.focusWidget()` 是 `QLineEdit` / `QTextEdit` 时不触发；
  - 其余情况（画布、目录、缩略图、工具栏空白）一律生效；
  - 侧栏控件可保留键盘导航，不再要求“先点画布”。
- 验收：点缩略图跳到第 5 页后，直接按 `B` 能切画笔；在查找框输入 `B` 仍然是字母 B。

#### E. 菜单重复、死项与作用域不一致（P1）

- “编辑 → 清空本页”和“工具 → 清屏”调用同一个 `_clear_active()`（`sketchpad/app.py:483-484`），名字却不同。
- “页面”菜单只有一个永远置灰的“页面信息”（`sketchpad/ui/menubar.py:146-150`）。
- 草稿模式下，“视图 → 放大/缩小/实际大小”仍可点击，但只会在状态栏提示“文档模式下才能缩放 PDF”；而滚轮却能缩放草稿。菜单状态与实际能力不一致。
- 快捷键作用域也和菜单不一致：`PgUp/PgDn`、`Ctrl+Shift+E` 在草稿模式仍注册，按下只会刷一条错误提示（`sketchpad/app.py:369-370`、`:664-668`）。
- 建议：合并为一个动态文案条目（草稿显示“清空画布”，文档显示“清空本页”）；删除“页面”菜单，或实现页面尺寸/旋转信息；草稿模式要么让菜单缩放生效，要么置灰；`PgUp/PgDn`、`Ctrl+Shift+E` 与对应菜单项使用同一个启用条件。

### 4.3 推荐键位方案

> 原则：**单键只给高频、非破坏性动作；组合键给全局动作；破坏性动作至少带修饰键；尽量贴合 PDF 阅读器与 Xournal++ 习惯。**

| 操作 | 现状 | 建议 | 说明 |
|---|---|---|---|
| 画笔 | `B` | `B`（保留） | Brush，通用 |
| 橡皮 | `Q` | `E` 为主，`Q` 保留为别名 | E=Eraser 更通用；Q 兼容老用户 |
| 荧光笔（新） | — | `H` | Highlighter |
| 框选（新，P2） | — | `V` | Select |
| 粗细 1–4 | `1–4` | `1–4`（保留） | 保持 |
| 颜色 1–8（新） | — | `Shift+1…8` | 不抢粗细键 |
| 清屏 / 清空本页 | `E` | `Ctrl+Delete` | 破坏性动作加修饰键；`E` 让给橡皮 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z` | 三键都支持 |
| 实际大小 100% | `0` | `Ctrl+0`，`0` 保留为别名 | 浏览器/PDF 阅读器习惯 |
| 放大 / 缩小 | — | `Ctrl+=` / `Ctrl+-` | 键盘缩放 |
| 适应页宽 | 仅菜单 | `Ctrl+9` | 与 100% 区分 |
| 上一页 / 下一页 | `PgUp/PgDn` | `PgUp/PgDn` | 建议改为“滚动 90% 视口”，到边界再翻页 |
| 首页 / 末页 | — | `Home` / `End` | 阅读器通用 |
| 跳转到页 | `Ctrl+G` | `Ctrl+J` 或状态栏内联输入 | 避免与“下一个命中”冲突 |
| 查找 | `Ctrl+F` | `Ctrl+F` | 保留 |
| 下一个 / 上一个命中 | `Enter` / `Shift+Enter`（仅输入框） | `F3` / `Shift+F3` + 原键 | 焦点离开也能继续 |
| 关闭查找 | `Esc` | `Esc` | 保留 |
| 保存批注 | `Ctrl+S` | `Ctrl+S` | 保留；菜单文案写“保存批注（sidecar）” |
| 导出已批注 PDF | `Ctrl+Shift+E` | `Ctrl+Shift+S` | “另存为”心智 |
| 导出当前页 PNG | — | `Ctrl+Shift+P` | 新增 |
| 全屏 / 阅读模式 | 仅菜单 | `F11` 进入，`Esc` 退出 | 菜单已有，补快捷键并隐藏 chrome |
| 设置 | `Ctrl+,` | `Ctrl+,` | 保留 |
| 草稿纸（全局） | `Ctrl+Alt+D` | 保留默认，可改 | AltGr 布局下需提示；允许 F1–F24 单键 |

**兼容策略**：旧键（`Q` 橡皮、`0` 复位、`Ctrl+G` 跳页）保留一个版本作为别名，设置面板里标注“旧键”，帮助里只展示新键。这样不会让现有肌肉记忆突然失效。

### 4.4 快捷键设计规则（写进后续开发约定）

1. **单键不出画布**：单键只在非文本输入焦点下生效；组合键才做全局。
2. **破坏性动作不绑裸键**：清屏、删除页、覆盖导出，至少 `Ctrl`/`Alt` 修饰。
3. **一个动作只有一个主键**：其余为别名，帮助里不展示别名。
4. **帮助即真相**：快捷键表从实际注册的 QShortcut/配置生成，禁止手写第二份。
5. **可发现**：工具按钮 tooltip、菜单项右侧、快捷键一览三处必须一致。
6. **可检测**：设置保存时检查与保留键、系统键、Qt 默认编辑键的冲突。

### 6.4 建议的功能细节

**高亮笔（F4）**
- 交互：拖拽画半透明粗线；默认 `Shift` 拉直；颜色建议 4 色（黄、绿、蓝、粉）。
- 数据：`Stroke` 增加 `kind: "pen" | "highlight"` 与 `opacity`；sidecar 版本号 +1，旧文件按 `kind="pen"` 读取。
- 导出：PyMuPDF 画线时用 `stroke_opacity=0.35`；先画高亮再画笔迹，避免盖字。
- 验收：屏幕与导出位置一致；文字仍可读；擦除按整笔。

**书签/续读（F6）**
- 交互：`Ctrl+D` 切换当前页书签；缩略图/页角显示书签；打开文档自动回到 `last_page`（可在设置关闭）。
- 存储：优先放 sidecar（跟文件走）；`bookmarks: [int]`、`last_page: int`、`last_zoom: float`。
- 风险：sidecar 版本升级要兼容旧文件；写入仍是原子写。
- 验收：重启程序后书签和上次页仍在；换机器复制 PDF + sidecar 后仍有效。

**导出当前页 PNG（F5）**
- 交互：`Ctrl+Shift+P` 或文件菜单；可选 1×/2×/3×。
- 实现：复用 `export_with_strokes` 的坐标变换，把单页画到临时 PDF 后 `get_pixmap`；或直接用 `QPainter` 画页面图和笔迹。
- 验收：旋转页、缩放页导出位置正确；透明背景可选（P2）。

**夜间阅读（F10）**
- 只对底图做亮度反相，笔迹颜色保持；再提供“降低对比度”滑杆更好。
- 不要直接反相整张合成图，否则红笔会变青色。
- 验收：白底变深灰、黑字变浅灰；高亮仍可辨；退出后恢复。

**阅读模式（F9）**
- `F11` 进入；隐藏标题/菜单/工具栏/状态栏；`Esc` 退出。
- 底部悬浮工具条只在鼠标靠近时出现；触控板用户可常驻。
- 与“全屏”菜单项合并，避免两个相似入口。

**草稿纸出口（F13）**
- 首次弹出应靠近鼠标所在屏，而不是屏幕正中（现在 `show_near_cursor()` 实际用的是屏中心）。
- 记住上次位置与尺寸；提供 480×320 紧凑模式。
- “复制为图片”最快；“送入主稿”需要定义偏移与是否清空草稿。
- 验收：`Ctrl+Alt+D` 呼出 → 写 → 复制 → 粘贴到聊天工具，内容完整。

## 8. 验收清单（以用户动作描述）

- [ ] 打开任意竖版 PDF，首屏能看到页首标题，而不是从正文中间开始。
- [ ] 打开横版 PDF，页面左右居中、顶部对齐。
- [ ] 标题栏始终显示文件名、当前页/总页数；有未保存批注时出现圆点。
- [ ] 点缩略图跳到第 5 页后，直接按 `B` 切画笔，按 `E` 切橡皮，不需要再点画布。
- [ ] 在查找框输入 `B` 仍是字母 B，不会切画笔。
- [ ] 清空查找框后，高亮立即消失，计数回到 `0/0`。
- [ ] 关闭查找条再打开，输入框为空、计数 `0/0`、无幽灵高亮。
- [ ] 深色模式下，目录树、滚动条、跳页输入没有白色大面积区域。
- [ ] 菜单里没有两个叫法不同但作用相同的清空项；“页面”菜单不再只有一个死项。
- [ ] 帮助 → 快捷键一览中的每一项都能在实际界面触发；没有缺项。
- [ ] 设置中把清屏键改成 `Ctrl+S` 会被拒绝并说明原因。
- [ ] 全局热键不允许裸字母；`F7` 和 `Ctrl+Alt+X` 合法。
- [ ] 关闭带未保存批注的文档时，出现“保存 / 丢弃 / 取消”三选一。
- [ ] 按 `F11` 进入阅读模式，`Esc` 退出；退出后工具栏和状态栏恢复。
- [ ] 520px 窄窗口下，工具栏有明确的横向滚动提示，或自动折叠为“更多”菜单；没有按钮被静默裁掉。
- [ ] 首次关闭主窗时，出现一次“程序仍在托盘运行”的提示。
- [ ] 草稿纸 `Ctrl+Alt+D` 呼出后，内容在隐藏/再次呼出之间保留；退出程序后按设计清空。
- [ ] 选择自定义颜色后，工具栏始终有一个可见的“当前色”指示。

## 9. 不做 / 暂缓

| 项 | 理由 |
|---|---|
| 云同步 / 账号 | 与“本地、离线、自用”定位冲突 |
| 协作批注 | 需要后端与权限模型，超出桌面小工具范围 |
| OCR / 全文识别 | 重依赖、重性能；先用 PyMuPDF 的文本层 |
| AI 摘要 / 问答 | 同上，且引入网络与隐私问题 |
| 插件系统 | 当前规模不值得；会拖慢启动与维护 |
| 富文本/排版编辑 | 不是批注工具的核心 |
| 草稿自动落盘 | 用户已明确“草稿关程序即丢”，保持现状，但要在首次使用提示 |
